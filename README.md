## Featured Projects

### 💳 Digital Wallet — Personal Project

**Tech Stack:** Java, Spring Boot, Spring Security, PostgreSQL, Redis, Kafka, WebSocket/STOMP, Flyway

A digital wallet backend designed to support secure financial transactions and real-time notifications.

- Implemented wallet management, top-up, money transfer, withdrawal, and transaction history.
- Built JWT authentication with refresh-token rotation, Google OAuth2 login, and role-based authorization.
- Applied database transactions, optimistic locking, and Redis idempotency keys to improve transaction consistency.
- Implemented an Outbox-based event-driven notification flow with Kafka, retry/DLT handling, and WebSocket/STOMP.
